## The word

**snackcident** (n.): the moment you open the fridge for one snack and accidentally eat dinner.

## How it works

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads `entry.txt` and writes the entry text to the output directory given by the `MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR` environment variable.

Run it with:

```sh
MAKEFUN_BOT_DIR=./out node main.ts
```
